# Homepage media

Place homepage demo videos and images here.

The homepage currently uses these static public paths:

- `hero-video.mp4`
- `hero-poster.png`
- `feature-build.png`
- `feature-wire.png`
- `feature-code.png`
- `feature-simulate.png`
- `ide-full.png`

Supported video formats depend on the browser. Prefer `.mp4` or `.webm`.
Feature media can be `.png`, `.webp`, `.avif`, or `.gif`.
