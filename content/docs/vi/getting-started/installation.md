# Cài đặt IDE

IDE có sẵn cho Windows, macOS và Linux. Vào trang Tải xuống để lấy trình cài đặt cho nền tảng của bạn.

## Windows

1. Tải file `.exe`
2. Chạy trình cài đặt và làm theo hướng dẫn
3. Khởi chạy **Drone Application by Insai** từ Start Menu

## macOS

1. Tải file `.dmg`
2. Mở disk image và kéo ứng dụng vào thư mục **Applications**
3. Lần đầu khởi chạy, nhấp chuột phải → Open nếu Gatekeeper chặn

## Linux

1. Tải file `.AppImage`
2. Cấp quyền thực thi: `chmod +x drone-app-insai-1.0.0-linux.AppImage`
3. Chạy: `./drone-app-insai-1.0.0-linux.AppImage`

## Yêu cầu hệ thống

| | Tối thiểu | Khuyến nghị |

| RAM | 8 GB | 16 GB |
